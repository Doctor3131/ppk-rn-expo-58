## APP Innit
Disini kita akan membuat project react-native menggunakan framework Expo. Link di bawah ini berisi informasi lebih detail mengenai React Native dan command untuk initialisasi React Native project. Tekan link di bawah atau gunakan langsung baris kode yang tertera. Pastikan node.js terinstall pada terminal. 

https://reactnative.dev/docs/environment-setup

```bash
# Initialisasi React Native project
# ikuti saja petunjuk yang ada, pilih opsi
# recommended atau y atau yes
# Pilih opsi SDK 58 (atau yang paling baru)

npx create-expo-app@latest
```

## Expo Configuration dengan EAS

Expo menawarkan dua cara untuk configurasi antara mobile dan desktop, yang dimana nantinya akan terinstal aplikasi di mobile sebagai development environment. Keduanya yaitu Expo Go dan Development Build. Expo Go menang di kemudahan setup nya, tetapi tidak bisa menambah library di luar config Expo. Oleh karena itu kita menggunakan opsi Development Build via EAS. Pastikan memilih Android / IOS device dengan opsi **Development build**.
[https://docs.expo.dev/get-started/set-up-your-environment/?mode=development-build](https://docs.expo.dev/get-started/set-up-your-environment/?mode=development-build)

Lebih lengkap maupun cara lain bisa baca berikut:
[Mobile Environment Configuration](docs/Mobile%20Environment%20Configuration.md)
